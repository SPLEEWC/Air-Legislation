# Air-Legislation

ME2804 Air Legislation learning games. `index.html` is the landing page that hosts all three games:

| Game | Folder | Slides covered |
|---|---|---|
| **Air Legislation Academy** – 3D adventure | `game/` | 1–42 (Chicago Convention, ICAO, ANA, ANO, SAR, UAS) |
| **9V Clearance** – tactical shooter | `ops/` | 43–63, 156–161 (Singapore Air Operator, C of A & Export C of A, Noise Certificate, Permit to Fly) |
| **Pencil Whip** – open-world driving | `whip/` | 64–73, 99–104, 110–127 (Aircraft Maintenance, CRS, CMR, Technical Log) |

Run locally:

```bash
python3 -m http.server 8000
```
